# Archive Directory

This directory contains archived files from the HyperRAG project development.

## Structure

### test-files/
Contains all test files used during development and testing phases.

### docs-archive/
Contains archived documentation files from various development phases:
- Phase 2 implementation docs
- Phase 3 completion summaries
- Phase 4 implementation summaries
- Phase-specific deployment guides

### Other Files
- Scripts used during development (deploy-alloy.sh, execute-phase2.sh, etc.)
- Fix scripts (fix-service-names.py, etc.)
- Test infrastructure scripts
- Development logs and results

## Note

These files are kept for reference but are not required for running the production system.
All essential components are in the main project directories.
